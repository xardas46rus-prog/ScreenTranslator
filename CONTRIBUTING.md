# Contributing / Разработка

Проект для Windows 10/11 x64 на Python 3.12. Все изменения вносятся через отдельные ветки и Pull Requests.

- Перед изменениями прочитайте `AGENTS.md`.
- Не добавляйте в Git `.venv`, API-ключи, пользовательскую историю, файлы моделей Argos/Ollama/Tesseract и приватные ключи подписи.
- Облачный перевод должен требовать явного согласия и персонального ключа пользователя.
- После изменений запускайте `python -m compileall -q screen_translator launcher tools`, а также тесты `tests` и `tests_launcher`.
- В PR отдельно описывайте проверку на Windows: OCR, Argos, Ollama, оверлей и EXE.
- Не обходите античиты и не управляйте игровым клиентом: инструмент работает только с изображением экрана.

GitHub Releases публикуются только после проверки подписей, EXE и ручного подтверждения владельца.
