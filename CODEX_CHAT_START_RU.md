# Как начать работать в чате Codex — ScreenTranslator

## 1. Открой Codex
Перейди на https://chatgpt.com/codex/ и войди в аккаунт ChatGPT.
Либо в приложении ChatGPT для Windows выбери режим **Codex**.

## 2. Подключи репозиторий
В Codex создай новый чат/задачу в облачном окружении и выбери репозиторий **xardas46rus-prog/ScreenTranslator**, ветка **main**. Если окружения ещё нет — создай и опубликуй окружение с этим репозиторием.
Важно: аккаунт GitHub должен быть **xardas46rus-prog**. Подключение GitHub к обычному чату ChatGPT ещё не гарантирует, что этот репозиторий выбран в окружении Codex.

Если репозиторий не виден, проверь подключение GitHub и доступ приложения Codex к этому репозиторию. Не используй другой заблокированный/неактивный аккаунт.

## 3. Первое сообщение в чате Codex (скопируй целиком)

> Работаем над ScreenTranslator в репозитории xardas46rus-prog/ScreenTranslator.
> Прочитай AGENTS.md, README.md и задачу https://github.com/xardas46rus-prog/ScreenTranslator/issues/2.
> Пока что репозиторий содержит документацию и CI, но не содержит исходников оригинального ScreenTranslator v3.3.2.
> Начни выполнение задачи #2: подготовь **отдельный чистый рабочий прототип** на Python 3.12 для Windows 10 x64, не выдавай его за оригинальную v3.3.2.
> Сделай минимальное русскоязычное Tkinter-окно, точку входа, тестируемую обработку OCR-текста, защиту от дублей и мусора скрытого игрового чата. Подготовь интерфейсы для OCR и локального перевода Argos/Ollama; никаких облачных запросов без согласия пользователя.
> Работай в отдельной ветке, запусти доступные тесты и создай Pull Request. Не публикуй Release, EXE, секреты или модели.
> Сначала кратко скажи, что нашёл в репозитории, затем переходи к реализации. Если возникнет препятствие, предложи безопасный обходной путь, не останавливаясь без необходимости.

## 4. Продолжай общаться в том же чате
После первого задания можно написать:
- «Исправь повторы сообщений и добавь тесты».
- «Улучши фильтрацию скрытого игрового чата».
- «Подключи локальный Argos с понятной диагностикой отсутствующей модели».
- «Добавь Ollama как опциональный локальный движок без обязательной установки».

Открывай **тот же разговор/задачу Codex** для продолжения, чтобы не терять незакоммиченные изменения. Pull Request нужно проверить перед слиянием.

## Что с настоящей версией v3.3.2
Это **не завершённый перенос оригинального переводчика**. Для точного переноса требуется архив `ScreenTranslator-Codex-Ready-Import-v3.3.2.zip` (или исходная папка проекта). Не загружай приватные API-ключи, локальные модели, .venv, журналы чатов и ключи подписи.

Когда архив появится, отдельной задачей импортируй оригинальные исходники в новую ветку, сравни их с прототипом, сохрани возможности OCR, Argos/Ollama, оверлея, лаунчера и только после проверки объединяй изменения.
