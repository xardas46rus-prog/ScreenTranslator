# ScreenTranslator 0.2.0 — развитие стартового прототипа

Это прототип задачи #2, расширенный заданием #3, для Python 3.12 / Windows 10/11 x64.
Исходники оригинальной v3.3.2 не импортированы. Подписанный лаунчер, автообновления,
откат и EXE пока не реализованы. Прототип не заменяет оригинал.
Оверлей и живой чат описаны в [отдельной инструкции](LIVE_CHAT_RU.md).

## Первый запуск на Windows

Установите официальный Python 3.12 x64 с компонентом Tcl/Tk. В каталоге проекта:

```bat
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m screen_translator
```

Для базового окна и ручного ввода дополнительных Python-пакетов не требуется.
Выберите исходный язык и провайдера. Вставьте текст игрового чата и нажмите
«Обработать введённый текст». По умолчанию выбран режим «Без перевода»: это
проверка фильтрации, а не настоящий перевод. Внутри одного ручного запуска
одинаковые строки выводятся один раз. Новый ручной запуск — отдельная проверка.

История хранится только в памяти и ограничена 100 сообщениями по 4096 символов на каждую сторону; приложение
не сохраняет настройки, изображения экрана, журналы чатов или API-ключи.

## Захват и Tesseract

```bat
.venv\Scripts\python -m pip install -r requirements-ocr.txt
```

Установите Tesseract OCR отдельно, например используя Windows-сборку, указанную
в [документации Tesseract](https://tesseract-ocr.github.io/tessdoc/Installation.html).
Установите языковые данные `eng` (английский), `chi_sim` (упрощённый китайский)
и при необходимости `rus` (русский). Укажите полный путь к `tesseract.exe`
в окне, если его нет в PATH. Пробелы в пути допустимы.

Нажмите «Выбрать мышью…» и выделите чат на основном мониторе. Esc отменяет выбор.
Для других мониторов задайте X/Y/ширину/высоту вручную; отрицательные X/Y допустимы.
При масштабировании Windows сначала проверьте соответствие координат на своём
мониторе. Окно переводчика должно находиться вне выбранной области.

Нажмите «Начать OCR». Один поток выполняет захват/OCR, другой — локальный перевод.
Интервал OCR настраивается (по умолчанию 0,25 с между началами циклов при достаточно
быстром распознавании); параллельные OCR-задания не накапливаются. Ожидающих переводов
не более 16. В быстром чате строка по умолчанию подтверждается двумя кадрами;
новые строки подтверждаются независимо от изменения остальных строк кадра.

Если игровой чат скрыт, **снимите флажок «Чат видим»**. В режиме быстрого чата захват и обработка будут
приостановлены, неподтверждённые строки сброшены. Перед возвращением включите
флажок снова. При выключенном «Быстром чате» обычный OCR области продолжает работать.
Фильтр OCR не может надёжно отличить текст чата от правдоподобного
текста игрового фона: автоматического определения видимости здесь нет.

Если Tesseract, Python-пакеты, язык или область недоступны, цикл останавливается
с объяснением в строке состояния. Ручной ввод остаётся доступен. «Остановить»
прерывает цикл между операциями; уже выполняющийся OCR имеет таймаут 5 с,
запрос Ollama — сетевой таймаут 15 с. Загрузка локальной модели Argos может
занять больше времени; она не прерывается принудительно.

## Необязательный Argos

```bat
.venv\Scripts\python -m pip install -r requirements-argos.txt
```

Установите совместимую локальную модель `en → ru` или `zh → ru` отдельно,
следуя [инструкции Argos](https://argos-translate.readthedocs.io/en/latest/).
Для локального файла `.argosmodel` можно использовать:

```bat
.venv\Scripts\python -c "import argostranslate.package as p; p.install_from_path(r'C:\Models\translate.argosmodel')"
```

Выберите «Argos (локально)». Приложение использует только установленные языки;
оно не обновляет каталог моделей и не скачивает модели. При отсутствии
пакета/направления выводится инструкция. Проверьте перевод на своей Windows-машине:
совместимость конкретных бинарных зависимостей и качество моделей здесь не гарантированы.

## Необязательный Ollama

Установите и запустите Ollama, заранее загрузите подходящую модель самостоятельно.
Выберите «Ollama (локально)», впишите её точное имя и включите отдельное разрешение
отправки текста этому локальному серверу. Без разрешения запрос не выполняется.

Используется только `http://127.0.0.1:11434/api/chat`. Удалённые адреса, прокси,
HTTP-перенаправления, автоматическая загрузка моделей и облачные API не поддерживаются.
Ответ модели считается переводом, но не исполняется как команда.

## Ограничения обработки игрового чата

- Нормализация Unicode NFKC и пробелов сохраняет алфавиты, имена и регистр.
  Кириллица не заменяется похожими латинскими буквами и наоборот.
- Отсекаются пустые, числовые, чрезмерно длинные и преимущественно символьные строки.
  Короткие китайские ответы допустимы. Это эвристика, её качество зависит от OCR.
- Повторы сравниваются без учёта регистра и лишних пробелов. Видимые строки
  не выдаются заново; одинаковое сообщение допускается через 30 с после исчезновения.
  Поэтому разные игроки с абсолютно одинаковым OCR-текстом без имени могут быть
  объединены. Ошибки OCR, изменяющие буквы, могут дать повтор.
- В памяти не более 256 ключей дедупликации; рассматриваются последние 40 строк
  из ограниченного фрагмента OCR-текста. Очередь результатов ограничена 64 событиями:
  при отставании окна самые старые события вытесняются.
- Очень быстрые/кратковременные сообщения могут не попасть в два кадра. Медленный
  перевод не блокирует OCR; переполнение очереди/истечение срока ожидания приводит
  к сбросу заданий со счётчиком в окне. Это прототип,
  не гарантия полного сохранения игрового потока.

Программа читает только пиксели выбранной пользователем области. Она не читает
память игры, не внедряется в процесс, не обходит античит и не управляет игрой.

## Проверка разработки

```bat
.venv\Scripts\python -m compileall -q screen_translator tests
.venv\Scripts\python -m unittest discover -s tests -p "test_*.py" -v
.venv\Scripts\python -m screen_translator --version
```

Тесты охватывают английские/русские/китайские строки, нормализацию, подтверждение,
прокрутку, скрытие, повторы, ограничение памяти/потока, остановку, ошибки адаптеров
и согласие на Ollama. Тесты провайдеров с подстановками не подтверждают качество
реальных моделей. CI запускает обработку текста на Ubuntu и Windows с Python 3.12.

Проверки окна включаются отдельно при наличии дисплея:

```bat
set SCREENTRANSLATOR_GUI_TESTS=1
.venv\Scripts\python -m unittest discover -s tests -p "test_gui.py" -v
```

В Linux можно использовать `SCREENTRANSLATOR_GUI_TESTS=1 xvfb-run -a .venv/bin/python
-m unittest discover -s tests -p 'test_gui.py' -v` при установленном Xvfb и Unicode-шрифтах.

Перед признанием Windows-версии рабочей вручную проверьте запуск без OCR/Argos,
выделение области при своём DPI и нескольких мониторах, английский/китайский OCR,
скрытие/возврат чата, остановку, реальный Argos и Ollama, отсутствие сетевых
запросов при выборе «Без перевода». EXE-сборка не входит в эту задачу.
Оверлей дополнительно проверьте по LIVE_CHAT_RU.md.

## Будущий импорт оригинала

Импорт v3.3.2 выполняется отдельной задачей после получения архива: сначала
сравнение файлов и поведения, затем согласование объединения. Не запускайте
скрипт безусловной перезаписи поверх прототипа. Не включайте в Git исходные
архивы, модели, `.venv`, пользовательские настройки, историю и ключи подписи.
