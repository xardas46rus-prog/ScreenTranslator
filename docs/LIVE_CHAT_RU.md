Пока PR #4 не принят, PR задания #3 имеет базу `feat/issue-2-clean-room-prototype`.
Порядок: владелец проверяет #4, затем проверяет зависимый PR; автоматического

Установка Python 3.12 x64, Tesseract и локальных движков — в
[PROTOTYPE_RU.md](PROTOTYPE_RU.md). Базовое окно и ручная проверка по-прежнему
работают без сторонних Python-пакетов. Версия: `python -m screen_translator --version`.

## Два вида вывода

«Отдельное окно» показывает прокручиваемую историю с крупным шрифтом. Флажок
«Исходный текст» добавляет оригинал перед переводом. «Свернуть настройки» скрывает
только настройки OCR/движка: кнопки, ручной ввод, история и работающая сессия остаются.
Размер шрифта ограничен 10–36 пт. История общая, до 100 сообщений; каждая сторона
обрезается до 4096 символов. Очистка истории не сбрасывает дедупликацию сессии.

«Оверлей» открывает отдельное always-on-top окно с той же историей переводов.
Перемещайте его за системный заголовок, меняйте размер за край. Регулятор
прозрачности задаёт непрозрачность 35–100%; размер шрифта настраивается отдельно.
Кнопка «В окно» или закрытие оверлея возвращает к основному окну, сохраняя сессию.
OCR и провайдер при переключении вывода не заменяются.

Оверлей **принимает клики**. Click-through и глобальные горячие клавиши не включены:
это управляемый fallback, исключающий ситуацию с недоступным для управления окном.
Для режима поверх игры предпочтителен оконный/безрамочный режим; отображение
поверх эксклюзивного fullscreen зависит от игры/ОС и не гарантируется.

На Windows запрашивается `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` для
собственных окон; это зависит от версии Windows (10 2004+) и графического стека.
Если функция недоступна, пересечение окна/оверлея с областью OCR ставит захват
на паузу с объяснением. Перемещение окна наружу возобновляет его автоматически.
**Всегда размещайте оба окна вне области OCR** и вручную проверьте отсутствие
самозахвата на своей Windows-машине: API не гарантирует исключение при любом драйвере.

## Быстрый чат и обычный OCR — разные режимы обработки

- Включён «Быстрый чат»: подтверждаются отдельные строки, отсекается символьный
  шум, сохраняются ники и EN/RU/中文. Повторы сравниваются после нормализации
  Unicode/пробелов и без учёта регистра. Алфавиты не транслитерируются.
- Выключен «Быстрый чат»: OCR **продолжает работать**, переводя стабильный блок
  выделенной области целиком, включая числа и короткие подписи. Без изменений
  один и тот же блок повторно не выдаётся.
- Интервал OCR 0,05–10 с, подтверждения 1–5 кадров, окно повторов 1–300 с задаются
  перед стартом. По умолчанию 0,25 с / 2 кадра / 30 с. Одно подтверждение быстрее,
  но пропускает больше OCR-шума. Номинальный интервал не ускоряет сам Tesseract.

При скрытии игрового чата снимите флажок «Чат видим» или нажмите **F8, когда фокус
в окне переводчика/оверлея**. Это не глобальная клавиша игры. В быстром чате
останавливаются новые OCR/переводы, очередь отменяется, неподтверждённые строки
сбрасываются. При возвращении подтвердите видимость снова. Результаты OCR/перевода,
начатые до скрытия, не попадают в новое поколение сессии, даже если чат быстро
открыли обратно. Ранее успешно выданные сообщения сохраняют дедупликацию.

При выключенном быстром чате флажок видимости игрового чата не приостанавливает
обычный перевод области. Для полной остановки используйте «Остановить».
Автоматического определения видимости чата нет: по OCR-тексту нельзя надёжно
отличить иероглифы чата от игрового фона. Если оставить флажок включённым при
скрытом чате, распознанный фон всё ещё может пройти текстовые фильтры.

## Ограниченный конвейер и восстановление

Один поток захватывает область и выполняет OCR; второй переводит. Медленная
Argos/Ollama не блокирует планирование OCR. В ожидании не более 16 заданий,
ещё одно может выполняться. При переполнении вытесняются старые задания;
старше 10 с задания и запоздалые ответы отбрасываются. Счётчики кадров,
очереди, переводов и отмен видны внизу окна. Очередь событий GUI ограничена 64;
при сильном отставании окна старые события также вытесняются.

Видимость, обычный/быстрый режим и применённый движок меняют поколение сессии.
Старые задания/ответы отменяются, захват продолжает работу. Текст, перевод которого
не был успешно выдан, может быть повторно поставлен в очередь, пока он видим.
Абсолютного отсутствия пропусков нет: быстрые реплики могут исчезнуть до нужного
числа кадров; при перегрузке в приоритете свежий текст. Ошибки OCR в буквах могут
выглядеть как новая реплика; одинаковые строки без разных ников объединяются.

Для смены провайдера выберите его и нажмите «Применить движок». По умолчанию
выводится оригинал. Для Ollama нужны имя установленной модели и явное согласие.
Снятие разрешения во время работы переключает движок на «Без перевода» и отменяет
очередь Ollama; уже начатый локальный запрос физически завершается в своём потоке.
Приложение не обращается к облачным API и не скачивает модели.

Ошибки Tesseract/языковых данных/Argos/Ollama останавливают сессию с русской
диагностикой. Исправьте причину и нажмите «Начать OCR» снова. Во время остановки
не запускается ещё одна пара потоков: нужно дождаться текущего OCR/перевода.
OCR имеет таймаут 5 с, Ollama — сетевой таймаут 15 с; загрузка Argos может длиться
дольше и не прерывается принудительно. UI и кнопка закрытия остаются доступны.

## Автоматические проверки

```bat
python -m compileall -q screen_translator tests
python -m unittest discover -s tests -p "test_*.py" -v
python -m screen_translator --version
```

Headless-тесты используют синтетические кадры и подстановки провайдеров: прокрутка,
многострочные кадры, короткие китайские ответы, шум, повтор/таймаут, пауза,
перезапуск после ошибки, переключение движка и поздние ответы. Блокирующий тестовый
переводчик проверяет, что OCR продолжает получать кадры и очередь не растёт без границ.
Эти тесты не требуют игры, Tesseract, моделей или сетевого сервера.

GUI-проверки включаются `SCREENTRANSLATOR_GUI_TESTS=1` с доступным дисплеем; без
Tk/дисплея они явно пропускаются. CI отдельно запускает их на Windows и через
Xvfb на Ubuntu. Это проверки Tkinter, а не подтверждение совместимости с игрой.

## Ручной чеклист Windows 10 x64

Не отмечайте пункт проверенным, пока он не выполнен на целевой машине.

- [ ] Python 3.12 x64: запуск без необязательных пакетов; ручной ввод; понятные ошибки отсутствующего OCR/Argos.
- [ ] Отдельное окно: EN/RU/中文 читаются; шрифт/прокрутка; настройки скрываются без минимизации и остановки сессии.
- [ ] Оверлей: поверх оконной игры; перемещение, resize, прозрачность 35–100%, возврат в окно и обратно с той же историей/сессией.
- [ ] Один и два монитора: выбор мышью на основном, ручные отрицательные X/Y на дополнительном; оба окна вне OCR.
- [ ] DPI 100%, 125%, 150%: границы выбранной области соответствуют реальным пикселям на каждом мониторе.
- [ ] Tesseract `eng`, `chi_sim`, `rus`: несколько новых строк, ник, скролл, короткие ответы, шум, сообщение повторно после исчезновения/таймаута.
- [ ] Скрытие и быстрое открытие чата: флажок/F8 в окне; фон не отправляется; нет запоздалых ответов старого поколения.
- [ ] Выключение «Быстрого чата»: обычный OCR продолжает работать, в том числе при снятом флажке видимости чата.
- [ ] Self-capture: проверить исключение окон на Windows 10 2004+; при неподдерживаемом исключении пересечение ставит capture на паузу.
- [ ] Реальные модели Argos `en→ru`/`zh→ru`, отсутствие модели и восстановление после её установки.
- [ ] Локальная Ollama: без согласия запросов нет; работа с установленной моделью; выключенный сервер/неверное имя; отзыв согласия; смена движка.
- [ ] Медленная модель: OCR продолжает получать кадры, очередь ≤16, отмены видны; пауза/остановка/повторный старт без второй пары потоков.
- [ ] Обычное закрытие окна и отсутствие новых запросов после завершения; никаких файлов истории/ключей/моделей в Git.
