Это упаковка **существующего прототипа 0.2.0**, не оригинал v3.3.2,
не подписанный релиз и не лаунчер обновлений. Основа — PR #5
(`feat/issue-3-live-chat-overlay`), который зависит от PR #4. Задача: #6.
Автоматического слияния или публикации GitHub Releases нет.

## Сборка на Windows

Нужен Windows x64, официальный **Python 3.12 x64** с Python Launcher (`py`)
и Tcl/Tk, Интернет к PyPI и несколько ГБ свободного места. Linux не собирает
Windows EXE. Для Argos/torch потребуется значительно больше места и времени.
Откройте cmd в checkout (допустимы пробелы и кириллица):

```bat
build_exe.bat
```

Базовый профиль включает Python, Tcl/Tk, mss, Pillow и pytesseract. Ручной ввод,
окно, оверлей, быстрый/обычный чат и Ollama сохранены. Внешний Tesseract нужен
только для OCR; Ollama не нужна для запуска. Для включения **библиотеки Argos**:

```bat
build_exe.bat --argos
```

Используются отдельные `.venv-build-portable` / `.venv-build-portable-argos`,
чтобы профиль OCR не подхватил ранее установленный Argos. Сборочные инструменты
и OCR-пакеты закреплены в `requirements-build.txt`; профиль Argos использует
полностью закреплённый Windows-граф `requirements-build-argos.lock.txt`.
Ограничения совместимости заданы в `requirements-build-argos.txt` (в том числе
protobuf 3.20.3 для старой stanza). Это не обещание побитово идентичной сборки.
Для осознанного обновления lock: `uv pip compile requirements-build-argos.txt
--python-platform windows --python-version 3.12 --no-header --no-annotate
--output-file requirements-build-argos.lock.txt`, затем заново проверить Windows CI.
Не используйте сборочное окружение для разработки или установки моделей.

PyInstaller использует `packaging/ScreenTranslator.spec` и явную точку входа
с `multiprocessing.freeze_support()`. Это `onedir`, без UPX. Python-модули и
Tcl/Tk упаковываются PyInstaller; доступ к исходникам через текущий каталог,
относительные файлы или расположение `sys.executable` приложению не требуется.
`sys.frozen` отражается в диагностике. В ZIP попадает только каталог результата
PyInstaller плюс эта инструкция и лицензия; checkout, `.venv`, настройки,
история, Tesseract и пользовательские модели не копируются.

Результаты: `build/` — промежуточные файлы, `dist/ScreenTranslator/` — приложение,
`dist/ScreenTranslator-ocr-prototype-unsigned-test-only.zip` либо
`ScreenTranslator-argos-prototype-unsigned-test-only.zip`. Сборка обновляет только
свои выходные каталоги; не храните в них пользовательские файлы или модели.
Они уже исключены из Git. Установленные модели не удаляются и не обновляются.

## Запуск без Python

Перенесите **весь ZIP**, распакуйте в отдельную папку и запустите
`ScreenTranslator/ScreenTranslator.exe`. Нельзя копировать один EXE:
рядом должны оставаться `_internal/` и все библиотеки. Не распаковывайте поверх
каталога с пользовательскими файлами; новую сборку проверяйте в новой папке.
Права администратора приложению не нужны. Сборка неподписанная; не отключайте
системные проверки безопасности ради запуска.

Приложение по умолчанию работает в режиме «Без перевода», не загружает модели
и не делает внешних запросов. Текст истории хранится только в оперативной памяти.
Новых файлов настроек или логов нет. Если настройки появятся в будущем, хранить
их следует отдельно в `%LOCALAPPDATA%\ScreenTranslator`, без истории и секретов.

Для консольной диагностики из cmd:

```bat
"C:\Тест переводчика\ScreenTranslator\ScreenTranslator-console.exe" --version
"C:\Тест переводчика\ScreenTranslator\ScreenTranslator-console.exe" --diagnose
"C:\Тест переводчика\ScreenTranslator\ScreenTranslator-console.exe" --smoke-test
```

`--version` возвращает `0.2.0-prototype` без GUI и движков. `--diagnose` выдаёт
JSON: версия, frozen и наличие модулей; он **не проверяет** DLL, OCR, модели или
работоспособность перевода. `--smoke-test` явно открывает Tk и оверлей, пропускает
EN/RU/中文 через ручной конвейер и закрывает окна. Он не захватывает экран,
не обращается к сети и не загружает модели. Нужен доступный рабочий стол.
У оконного EXE нет консоли; для текста ошибок используйте консольный EXE.
Ошибки обычного старта оконного EXE показываются системным диалогом.

## OCR, Argos и Ollama

- **Tesseract:** установите x64 по ссылкам из
  [официальной инструкции](https://tesseract-ocr.github.io/tessdoc/Installation.html),
  отдельно добавьте языки `eng`, `chi_sim`, `rus`. В GUI укажите полный путь,
  например `C:\Program Files\Tesseract-OCR\tesseract.exe`, без кавычек внутри поля.
  Ошибка отсутствующего языка/движка отображается в статусе; ручной ввод доступен.
- **Argos:** для EXE нужен ZIP профиля `argos`: установка через pip рядом с
  уже собранным EXE не добавляет в него Python-пакеты. Модели `en→ru` и `zh→ru`
  установите отдельно для того же Windows-пользователя по
  [инструкции Argos](https://argos-translate.readthedocs.io/en/latest/).
  Приложение использует установленные модели через штатный каталог Argos,
  не обновляет индекс и не скачивает модели. Отсутствующие пакет/модель дают
  понятную ошибку. В базовом ZIP Argos отсутствует намеренно.
- **Ollama:** отдельная локальная установка и заранее установленная модель.
  Укажите имя модели и явно разрешите передачу текста локальному серверу.
  Сохраняется контракт `127.0.0.1:11434`, без прокси, редиректов и загрузки моделей.
  Без согласия запросов нет. Ни сервер, ни модели не включаются в ZIP.

## Actions: только временный тестовый артефакт

В Actions откройте запуск **Screen Translator checks** для текущего PR/ветки,
дождитесь успеха Windows portable jobs `ocr` и `argos`. В разделе Artifacts
скачайте `ScreenTranslator-windows-x64-<профиль>-prototype-unsigned-test-only`.
GitHub может потребовать вход. Распакуйте оболочку артефакта, затем вложенный ZIP
с приложением. Срок хранения — 7 дней. Это не страница Releases.

CI выполняет Python-тесты с GUI, сборку обоих профилей, `--version` обоих EXE,
`--diagnose`, затем GUI/overlay smoke обоих EXE после распаковки ZIP в **другой
каталог с пробелами и кириллицей**. При сбое артефакт не выгружается.
`windows-latest` не является чистой Windows 10: наличие Python на runner и
синтетический ввод не подтверждают работу на пользовательской машине.

## Фактическая проверка и ручной чеклист

Результаты конкретного запуска Python/CI приведены в PR; команды:

```bat
python -m compileall -q screen_translator tests tools packaging
python -m unittest discover -s tests -p "test_*.py" -v
python -m screen_translator --version
python tools/smoke_portable.py dist/ScreenTranslator-ocr-prototype-unsigned-test-only.zip
python tools/smoke_portable.py dist/ScreenTranslator-argos-prototype-unsigned-test-only.zip --argos
```

Все следующие пункты **не проверены**, пока владелец не выполнит их на Windows:

- [ ] Чистая Windows 10 x64 **без Python**: ZIP вне исходников, путь с пробелами
      и кириллицей, запуск и корректное закрытие обоих EXE.
- [ ] Отдельное окно ↔ оверлей, прозрачность, перемещение, сохранение истории,
      EN/RU/中文, окно поверх оконной/безрамочной игры.
- [ ] DPI 100/125/150%, выбор области, дополнительный монитор, отсутствие self-capture.
- [ ] Настоящий Tesseract eng/chi_sim/rus, быстрый и обычный режим, скрытие чата,
      отсутствие дублей, остановка и повторный старт.
- [ ] Реальный Argos en→ru/zh→ru; отсутствие модели/библиотеки без закрытия окна.
- [ ] Локальная Ollama: согласие, перевод, недоступный сервер, отзыв согласия.
- [ ] Нет внешних запросов при старте; существующие модели и пользовательские
      каталоги сохранены; нет моделей, секретов и истории в ZIP.

Расширенный сценарий и ограничения — [LIVE_CHAT_RU.md](LIVE_CHAT_RU.md).
