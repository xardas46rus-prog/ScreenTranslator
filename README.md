# ScreenTranslator — EN / 中文 → RU

Экранный переводчик для Windows 10/11 x64: распознавание выбранной области экрана, автоматический перевод английского и китайского текста на русский, режим оверлея и отдельного окна, быстрый игровой чат.

**Целевая версия исходников:** v3.3.2. Поддержка Argos (локально), Ollama (локально), а также подключаемых OpenAI/GigaChat с персональными API-ключами. Предусмотрен отдельный лаунчер для подписанных обновлений через GitHub Releases.

## Прототип 0.2.0 — живой чат и оверлей

В ветке разработки задачи #2 добавлена **новая минимальная реализация**, а не
перенос оригинальной v3.3.2. Есть русское Tkinter-окно, ручная проверка текста,
выбор области экрана, необязательный Tesseract OCR и адаптеры локальных Argos/Ollama.
Задание #3 расширяет существующий прототип: отдельные потоки OCR/перевода,
быстрый чат, обычный перевод области, сворачиваемые настройки и оверлей
с прозрачностью. Лаунчер, подписанные обновления и EXE пока не реализованы.

**[Живой чат, оверлей и ручной чеклист Windows](docs/LIVE_CHAT_RU.md).**

**[Запуск прототипа на Windows и ограничения](docs/PROTOTYPE_RU.md).**

```bat
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m screen_translator
```

Ручная обработка работает без сторонних Python-пакетов. Без выбранного локального
провайдера показывается исходный текст. Для OCR и перевода нужны отдельные
необязательные зависимости, описанные в инструкции.

## Состояние репозитория

Оригинальные исходники v3.3.2 ещё не импортированы. Наличие `screen_translator/`
теперь означает наличие стартового прототипа и **не подтверждает импорт оригинала**.
Для переноса потребуется исходный архив и отдельное сравнение с прототипом.
Не запускайте импорт с безусловной перезаписью файлов.

Читайте [AGENTS.md](AGENTS.md), [CODEX_START_RU.md](CODEX_START_RU.md) и [CONTRIBUTING.md](CONTRIBUTING.md).

### После импорта исходников

```bat
python -m compileall -q screen_translator launcher tools
python -m unittest discover -s tests -p "test_core.py"
python -m unittest discover -s tests_launcher -p "test_*.py"
```

GUI, OCR через Tesseract, Argos, Ollama и EXE-пакетирование требуют отдельного тестирования на Windows. Автоматическая сборка в GitHub Actions не является подтверждением работы Windows-оверлея.

### Проверки текущего прототипа

```bat
.venv\Scripts\python -m compileall -q screen_translator tests
.venv\Scripts\python -m unittest discover -s tests -p "test_*.py" -v
.venv\Scripts\python -m screen_translator --version
```

На Linux используйте `.venv/bin/python`. GUI требует дисплей и Tkinter;
модули обработки текста и их тесты запускаются без GUI.

**Приватность:** никогда не загружайте `.venv`, пользовательские настройки, API-ключи, модели Tesseract/Argos/Ollama и закрытые ключи подписи. Облачные запросы выполняются только после согласия пользователя и с его собственным ключом.

Публичные релизы публикуются отдельно после ручной проверки.
